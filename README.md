# TaskFlow — SaaS Landing Page

A responsive front-end landing page for a fictional project and task management SaaS product. Created for the Sankar Group Front-End Development Internship Assignment.

## Features
- Responsive desktop and mobile layout
- Sticky navigation with mobile menu
- Hero section with custom CSS dashboard illustration
- Features and "How it works" sections
- Starter and Pro pricing cards
- Monthly/yearly pricing toggle
- Demo request form with HTML/JavaScript validation and success feedback
- Footer with in-page navigation

## Technologies
- HTML5
- CSS3 (Flexbox, Grid, media queries)
- Vanilla JavaScript
- Google Fonts (Manrope and DM Sans)

## Run locally
1. Download or clone this repository.
2. Open the `TaskFlow` folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. No package installation or build step is required.

## Project files
- `index.html` — page structure and content
- `style.css` — visual design and responsive styles
- `script.js` — mobile navigation, pricing toggle, and form validation

## Notes
This is a front-end demonstration. The demo form does not send data to a backend, and the pricing cards do not process payments. The contact email and product details are illustrative placeholders.

## Design explanation (submission-ready draft)
TaskFlow uses a clean SaaS-style layout with a purple accent palette to create a modern and consistent visual identity. The page is organised into clear sections so visitors can quickly understand the product, its features, and pricing. A CSS-built dashboard illustration gives the hero section a product-focused visual without requiring external image assets. CSS Grid, Flexbox, and media queries make the layout adapt to mobile and desktop screens. JavaScript powers the mobile navigation, monthly/yearly pricing switch, and demo form validation. The form displays a success message on valid submission; no backend is required for this assignment. I focused on readable typography, consistent spacing, accessible labels, and simple interactions.
